# Colmado Dash — Final Export Steps for Xcode

## Prerequisites
- Godot 4.3 installed (with iOS export templates)
- Xcode 15+ installed
- Apple Developer account with Team ID: **F67M3W45C6** (Pedro Javier)
- iPhone plugged in via USB

---

## Step 1: Open in Godot

```
File → Open Project → navigate to ~/colmado-godot → select project.godot
```

When Godot opens, click **Reimport** if prompted (reimports all assets).

---

## Step 2: Verify iOS Export Templates

Go to: **Editor → Manage Export Templates**

If templates are missing, download them for Godot 4.3.

---

## Step 3: Export for iOS

1. Go to **Project → Export**
2. Select **iOS** preset (already configured)
3. Click **Export Project**
4. Save to Desktop as: `ColmadoDash`
5. Godot will create `ColmadoDash.xcodeproj` + supporting files

---

## Step 4: Open in Xcode

```
open ~/Desktop/ColmadoDash/ColmadoDash.xcodeproj
```

Or double-click `ColmadoDash.xcodeproj` in Finder.

---

## Step 5: Configure Signing

In Xcode:
1. Click the **ColmadoDash** project in the left panel
2. Select the **ColmadoDash** target
3. Go to **Signing & Capabilities** tab
4. Set **Team** = `F67M3W45C6` (Pedro Javier)
5. Bundle Identifier should auto-fill as: `com.pjavier.colmadodash`
6. Make sure "Automatically manage signing" is checked

---

## Step 6: Run on iPhone

1. Plug in your iPhone via USB
2. Trust the computer on the iPhone if prompted
3. In Xcode, select your iPhone from the device picker (top toolbar)
4. Press **▶️ Run** (Cmd+R)

The app will build, install, and launch on your iPhone automatically.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "No export templates" | Editor → Manage Export Templates → Download |
| "Provisioning profile missing" | Xcode → Signing → let it auto-fix |
| "untrusted developer" on iPhone | iPhone Settings → General → VPN & Device Mgmt → Trust Pedro Javier |
| Black screen on launch | Check Godot renderer = mobile in project.godot |
| Export path error | Make sure Desktop folder exists, or choose a different save path |
